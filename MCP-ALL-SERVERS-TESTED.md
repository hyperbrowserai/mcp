## 🔧 How to Fix Not Working Servers

### Cloudflare Services (14 servers)
These require Cloudflare API tokens:

```bash
# Set Cloudflare API token
export CLOUDFLARE_API_TOKEN="your-api-token-here"

# Or configure via Docker MCP
docker mcp config set CLOUDFLARE_API_TOKEN="your-api-token-here"

# Then test
docker mcp server inspect cloudflare-ai-gateway
```
